# Contoso — Support Playbook

When a customer reports a wrong number on a dashboard:

1. Confirm which metric and which definition they expect.
2. Check the metric owner and the last definition change in the audit log.
3. If the definition changed, explain the change; if it is a bug, escalate.

Response-time target is one business day for standard plans.
